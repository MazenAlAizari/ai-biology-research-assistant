## 🔄 نظام العمل اليومي

هذه أهم نقطة في المشروع كله. المساعد لا يقول: "أعطني 5 أبحاث كل يوم"، بل يعمل بهذه الطريقة:

```
التاريخ المحدد
    ↓
البحث في المصادر المسموحة
    ↓
العثور على الأبحاث الحديثة
    ↓
التحقق من الورقة وبياناتها
    ↓
تحديد الفرع المناسب (🤖 AI أو 🧬 Biology)
    ↓
فحص سجل الأبحاث السابقة
    ↓
استبعاد أي بحث مكرر
    ↓
استبعاد أي بحث غير موثوق أو غير قابل للتحقق
    ↓
إضافة الأبحاث الجديدة فقط
    ↓
ترقيمها داخل الفرع الخاص بها
    ↓
إخراج المنشورات الجاهزة للنشر
```

راجع تفاصيل القواعد الكاملة في [`RULES.md`](./RULES.md).

## ✍️ طريقة الإضافة اليومية

1. حدد التاريخ.
2. ابحث في المصادر المعتمدة للفرع المطلوب.
3. تحقق من كل ورقة (DOI ← معرف الورقة ← الرابط الأصلي ← العنوان ← بيانات الورقة).
4. راجع `research-log.md` الخاص بالفرع واستبعد أي بحث مكرر.
5. أنشئ نسخة جديدة داخل الفرع باستخدام `TEMPLATE.md`، ورقّم الأبحاث الجديدة فقط (Research 01، 02...).
6. أضف كل بحث جديد نُشر إلى `research-log.md` (العنوان + DOI/الرابط + التاريخ) حتى لا يتكرر مستقبلاً.
